Map every path from your app's code to its database.

tracegrid joins your Supabase schema (grants, RLS, functions, edge functions, storage) with every call site in your code, then reports what's exposed but never used: functions anon can run that nothing calls, client-read tables without RLS, owner-rights views.

How it works

01 · Schema

Replays your Supabase migrations, or reads the live catalog read-only with --db-url: tables, functions, grants, RLS.

02 · Code

Parses your code with the TypeScript parser for .from, .rpc, functions.invoke and storage calls.

03 · Graph

Joins both into one graph and reports exposure with no caller, the direction most tools skip.

Run it on your app

cd your-app && npx tracegrid

Writes report.md, graph.json and graph.html to ./tracegrid-out/. Node 20+.

Gate pull requests

- run: npx --yes tracegrid@0.2.1 --check --github --no-plugins

--check fails only on new Fix findings not in your baseline. Built for fork-PR CI: plugins off, read-only, escaped output. CI guide · Security model
